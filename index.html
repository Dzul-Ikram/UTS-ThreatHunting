1. Executive Summary & Ringkasan Studi Kasus

Kasus Ujian THCTI

Investigasi threat hunting ini dilakukan terhadap telemetri riil Security Operations Center (SOC) enterprise dari dataset WitFoo Precinct 6 (witfoo/precinct6-cybersecurity). Berdasarkan korelasi multi-sensor, diidentifikasi kampanye serangan data theft terkoordinasi (Partition 233678) pada organisasi ORG-0003 yang berlangsung pada 2 Juni 2023.

Serangan berpusat pada insiden kritis 25512200-01d5-11ee-8c41-374f8f3a6a1c (Defiant Pike 233678) dengan skor kecurigaan tertinggi 0.859. Pada insiden ini, host internal terkelola 192.168.96.104 (segmen resepsionis nirkabel NORHQ_WAP_RECEPTION) berupaya melakukan exfiltration data dan koneksi Command & Control (C2) keluar menuju IP eksternal 100.64.43.120 pada port HTTPS 443.

Korelasi multi-telemetri mengonfirmasi bahwa FireEye Endpoint Security (HX) mendeteksi kecocokan domain reputasi berbahaya (FireEye HX Domain Match), sementara Cisco Stealthwatch NDR memicu Stealthwatch High Concern Index Alarm atas indikasi penimbunan dan transmisi data abnormal. Perimeter gateway berhasil melakukan disrupsi (status: Disrupted), namun pada saat bersamaan terdeteksi aktivitas pemindaian lateral di kantor cabang Atlanta, Conyers, Loxley, dan Northbrook.

6. Threat Hunting Queries & Detection Rules (Soal 5)

Bobot: 20 Poin

Query 1: Cross-Source Temporal Join (EDR Threat Match + Denied Outbound HTTPS Flow)

Platform: Splunk SPL / Elastic EQL
```spl (index=edr product_name="FireEye Endpoint Security*" matched_rules="*Domain Match*") OR (index=network message_type="firewall_action" action IN ("deny", "block") dst_port=443) | eval hunting_ip = coalesce(src_ip, clientip) | stats earliest(_time) as first_seen, latest(_time) as last_seen, values(product_name) as sensors, values(matched_rules) as triggered_rules, values(dst_ip) as target_c2, count by hunting_ip | where mvcount(sensors) >= 2 AND count >= 2 | eval time_window_seconds = last_seen - first_seen | where time_window_seconds <= 300 ```
Field yang Dicari: src_ip, dst_ip, dst_port=443, matched_rules, product_name, action.
Kemungkinan False Positive: Software update browser/antivirus yang menghubungi mirror IP baru yang masuk blackhole DNS sementara.
Detection Tuning: Filter whitelist CDN Microsoft/AWS terverifikasi, terapkan threshold minimum 2 produk security berbeda.

Query 2: Multi-Branch Lateral Probing & Port Sweeping Detection

Platform: Python Pandas / SQL Analytics / Precinct Engine
```python # Python / Pandas Hunting Engine Query suspicious_ports = [13731, 8880, 4112, 4010] hunting_sweep = df[ (df['protocol'] == 'tcp') & (df['dst_port'].isin(suspicious_ports)) & (df['action'].isin(['deny', 'block', 'drop'])) ].groupby(['src_ip', 'stream_name']).agg( distinct_targets=('dst_ip', 'nunique'), target_list=('dst_ip', lambda x: list(x.unique())[:5]), probe_count=('dst_port', 'count'), min_time=('timestamp', 'min'), max_time=('timestamp', 'max') ).reset_index() # Filter high anomaly threshold (scanning > 5 internal hosts) alert_candidates = hunting_sweep[hunting_sweep['distinct_targets'] >= 5] ```
Field yang Dicari: dst_port IN [13731, 8880, 4112, 4010], dst_ip (nunique), src_ip, stream_name.
Kemungkinan False Positive: Vulnerability scanner internal terjadwal (Nessus/Qualys) atau automated backup daemon.
Detection Tuning: Kecualikan IP scanner terdaftar dalam CMDB SOC, aktifkan dynamic alert scoring jika terjadi di luar jam kerja.
